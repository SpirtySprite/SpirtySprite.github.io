Overview

Place a crate, right click it with a key to open it, left click to preview the rewards. Sneak to open with every key at once in a dedicated animation. Rewards that don't fit drop at the player's feet.

Install

Build the jar with mvn package from the repository, or grab it from the releases page, then drop it into plugins/ and start the server. The config, the language files and the examples are written on first start.

Set language: en or language: fr in config.yml. PlaceholderAPI and Vault are optional.

What's inside

12 opening animationscsgo, roulette, cascade, wheel, pulse, raffle, lightning, clock, wave, zoom, mosaic, instant.
12 bulk animationsdomino, avalanche, spiral, explosion, implosion, mirror, curtain, scanner and more.
KeysVirtual and physical keys, a free daily key and key purchases through Vault.
FairnessPity guarantees a rarity after unlucky streaks; stats compare stated and observed chances.
ProgressOpening milestones with money, commands and messages, repeatable or not.
LooksParticle effects around blocks, per-player holograms and ModelEngine models.
RewardsItems, money, commands, unique once-per-player rewards and server announcements.
EditorEvery crate, reward, animation and effect is editable from /crate admin.

Commands

CommandEffect
/crate admincreate, edit, place and remove crates
/crate preview <crate>reward preview
/crate open <crate>opens a crate without a block
/crate historywin history
/crate import <source>imports crates and keys from another plugin
/cle give <player> <crate> [amount]gives virtual keys (/key works too)
/cle all <crate> [amount]gives keys to every online player

Moving from another plugin

SourceReads
crazycratescrates/*.yml in both prize formats, and virtual keys from data.yml
excellentcratescrates/*.yml with vanilla items, and virtual keys from its SQLite database

Weights keep their proportions, commands keep working with <player>, and key balances are added to each player. Anything that can't be carried over is listed in the console.

Developer API

Example.java
LootriftApi.get().ifPresent(lootrift -> {
    lootrift.giveKeys(player.getUniqueId(), "rare", 3);
    lootrift.open(player, "rare");
});

CrateOpenEvent fires before a key is used and can be cancelled. CrateRewardEvent fires after each reward is delivered, with the reward id, rarity, amount and money.
