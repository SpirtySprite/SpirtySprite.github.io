# KiruProject

The project site for my Paper and Folia libraries and plugins, live at
[spirtysprite.github.io](https://spirtysprite.github.io).

| Project | Kind |
|---|---|
| [FoliaGUI](https://spirtysprite.github.io/foliagui/) | inventory menu library |
| [FoliaBoard](https://spirtysprite.github.io/foliaboard/) | scoreboard, nametag and tab list library |
| [FoliaNPC](https://spirtysprite.github.io/folianpc/) | packet NPC library |
| [Itemsmith](https://spirtysprite.github.io/itemsmith/) | in-game item editor |
| [Puppeteer](https://spirtysprite.github.io/puppeteer/) | NPC plugin |
| [Lootrift](https://spirtysprite.github.io/lootrift/) | crate plugin |
| [Loadout](https://spirtysprite.github.io/loadout/) | kit plugin |

## Editing

The site is plain HTML, CSS and JavaScript served straight from `main`, with no build step on GitHub.
Every page is generated by `tools/build.py`, which holds the text of each project:

```bash
python tools/build.py .
```

Styles live in `assets/site.css`, the region map and the copy buttons in `assets/site.js`. The build
stamps both files into the page links, so browsers pick up a change right away.
