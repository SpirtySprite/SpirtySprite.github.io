Overview

Itemsmith turns item editing into a menu. Hold anything, run /item, and change its name, description, enchantments, attributes, hide flags, model, tooltip style, rarity, colour, head, durability and more. Text is typed on a sign, and every change goes into an undo history.

Install

Build the jar with mvn package from the repository, or grab it from the releases page, then drop it into plugins/ and start the server. The config, the language files and the examples are written on first start.

Set language: en or language: fr in config.yml. PlaceholderAPI and Vault are optional.

What you can edit

TextName and lore with MiniMessage, line by line, with move, insert and delete.
EnchantmentsAny enchantment at any level, even when the item can't normally hold it.
AttributesAdd, multiply or percentage modifiers, per slot.
LooksItem model, custom model data, tooltip style, glint, rarity, colour, trims.
BehaviourMax stack, durability, unbreakable, glider, fire resistance, repair cost.
Special itemsPlayer heads and textures, potions, written books.

Commands

CommandEffect
/itemopens the editor for the item in your hand
/item edit <field> ...edits one field directly, see /item help
/item undoundoes the last change
/item infosummarises the item in your hand
/item reloadrereads the config and language files

Aliases: /itemedit, /ie, /itemeditor, /edititem. Everything needs itemsmith.admin.item, given to operators by default.

Developer API

Example.java
ItemsmithApi.get().ifPresent(itemsmith -> itemsmith.openEditor(player));

ItemEditEvent fires before an edit replaces the item in hand. It carries copies of the item before and after; cancelling it keeps the original and leaves the undo history untouched.
