Overview

Loadout ships fourteen example kits and an in-game editor for all of them. Players browse kits by category, try the gear on before claiming it, and watch an animated ceremony when they claim.

Install

Build the jar with mvn package from the repository, or grab it from the releases page, then drop it into plugins/ and start the server. The config, the language files and the examples are written on first start.

Set language: en or language: fr in config.yml. PlaceholderAPI and Vault are optional.

What's inside

TimingCooldowns, daily, weekly or monthly resets, time windows, days of the week, limited periods.
ConditionsPermission, playtime, level, balance, worlds, statistics and required kits.
MasteryKits level up as they are claimed: shorter cooldowns, bonus rewards, extra draws.
Streaks and collectionClaiming every reset builds a streak; collecting kits unlocks milestones.
Featured kitOne paid kit rotates daily with a discount.
Vouchers and giftsPhysical vouchers and paying a kit for another player.
Random drawsPools with weights, unique draws and an animated roulette.
Special kitsFirst join, respawn, team kits, temporary items and unsellable items.

Commands

CommandEffect
/kitkit menu
/kit <kit>claims a kit
/kit preview <kit>, /kit tryon <kit>preview, or wear the gear before claiming
/kit gift <player> <kit>pays a kit for someone else
/kit allclaims every free kit that is ready
/kit adminadmin menu and editor
/kit import <source>imports kits and cooldowns from another plugin

Moving from another plugin

SourceReads
essentialskits.yml, item aliases from items.json, and each player's last claim
ultimatekitskit.yml with its NBT items, and each player's last claim

Armour lands in armour slots, money and commands become rewards, and running cooldowns keep going.

Developer API

Example.java
LoadoutApi.get().ifPresent(loadout -> {
    if (loadout.available(player, "daily")) {
        loadout.claim(player, "daily");
    }
});

KitClaimEvent fires before anything is paid or given and can be cancelled. KitClaimedEvent fires after delivery with the items and the new mastery level.
